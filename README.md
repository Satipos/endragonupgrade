# End Dragon Upgrade

Мод для Minecraft 26.1.2 (Fabric + Fabric API), превращающий обычного Эндер
Дракона в усиленного босса с тремя стадиями и новыми атаками.

## Как пользоваться

1. Установите Fabric Loader `>= 0.19.2` и Fabric API `0.146.1+26.1.2`
   (или новее совместимую версию) для Minecraft 26.1.2.
2. Положите `endragonupgrade-1.0.0.jar` в папку `mods`.
3. Запустите игру, начните бой с Эндер Драконом.
4. Пока дракон жив, напишите в чат ровно: `Endo espo dragonio di quoro.`
5. Дракон на 3 секунды застынет в облаке частиц портала Края (звук
   грома + звук портала), затем перейдёт в боевой режим.

## Стадии

| Стадия | HP        | Поведение |
|-------|-----------|-----------|
| 1     | 100 – 50 % | Учащённые рывки, за драконом тянется облако драконьего дыхания. |
| 2     | 50 – 25 %  | + каждые 8 с призывает двух Эндермитов, каждые 3 с плюёт фиолетовыми фаерболами (при попадании остаётся облако дыхания). |
| 3     | 25 – 0 %   | + каждые 12 с бьёт ударной волной в центр острова: радиус 15 блоков, урон 8, сильное отбрасывание. |

На каждом переходе стадии:

- у всех игроков дрожит камера (~1 с);
- играет звук `entity.wither.spawn`;
- в чат приходит: `Дракон впадает в ярость! Стадия X`.

## Кастомный HP-бар

Стандартный босс-бар дракона заменён собственным HUD-элементом:
широкая фиолетовая полоса с тёмной рамкой, отметками 50 % и 25 %,
названием и численным HP. Рендерится через `HudElementRegistry`
(в 26.1 старый `HudRenderCallback` был удалён).

## Текстура

В `assets/endragonupgrade/textures/entity/enderdragon/` лежат
производные от ванильных текстур `dragon.png` и `dragon_eyes.png` в
фиолетовой гамме со светящимися глазами. Поскольку спецификация
запрещает Mixin'ы, подмена рендерера дракона не выполнена: текстуры
упакованы в jar для желающих сделать resource pack, просто скопировав
их в `assets/minecraft/textures/entity/enderdragon/`.

## Сборка из исходников

Требуется JDK 25.

```bash
export JAVA_HOME=/path/to/jdk-25
./gradlew build
```

Собранный мод появится в `build/libs/endragonupgrade-1.0.0.jar`.

## Архитектура

- `EndRagonUpgradeMod` — точка входа (`ModInitializer`), регистрирует
  сетевые пакеты, чат-листенер и серверный тикер.
- `ChatActivation` — подписка на `ServerMessageEvents.ALLOW_CHAT_MESSAGE`,
  ловит активационную фразу и помечает живого дракона как усиленного.
- `DragonRegistry` / `EmpoweredDragonState` — runtime-состояние каждого
  усиленного дракона (таймеры кулдаунов, текущая стадия, freeze).
- `DragonBehavior` — `ServerTickEvents.END_SERVER_TICK`, управляет
  анимацией заморозки, сменой стадий, атаками и рассылает
  кастомные payload-пакеты клиенту.
- `attack.PurpleFireballAttack` / `attack.ShockwaveAttack` — сами атаки.
- Клиент: `EmpoweredHealthBar` (HUD), `ScreenShakeHandler` (дрожание
  камеры), `ClientNetworkHandler` (приём payload'ов).

Никаких Mixin'ов — только Fabric API хуки.
